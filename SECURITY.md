# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities in public issues.**

Report them privately through GitHub:
[**Report a vulnerability**](https://github.com/hyunsoo3787/flowbit/security/advisories/new)
(repository → Security → Advisories → Report a vulnerability).

Please include:

- a description of the issue and its impact,
- steps to reproduce, or a proof of concept,
- the affected version or commit.

We aim to acknowledge reports within 3 business days and to keep you updated
until the issue is resolved. We are happy to credit you in the advisory.

## Supported versions

Flowbit has not had a stable release yet. Until `v1.0`, security fixes are made
on the `main` branch only.

## Scope

In scope: the code in this repository, including the Docker image and Compose
files. Out of scope: vulnerabilities in third-party dependencies that are
already public (please report those upstream), and issues that require a
compromised server or administrator account.
